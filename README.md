# 獵頭工具

- `index.html`：獵頭工作台（職缺、人選進度、待辦）
- `screener/`：**履歷篩選推薦工具**（本文件說明）

## 履歷篩選推薦工具

貼上職缺 JD 與補充資訊，工具會從你的人才庫中找出最合適的人選。每位人選都會列出：

| 項目 | 說明 |
|---|---|
| 評分 | 0–100 分，依 JD 拆出的評分維度加權 |
| 合適度 | 強烈推薦／推薦／可考慮／不推薦 |
| 推薦原因 | 引用履歷中的具體經歷與成就 |
| 必要條件檢核 | 逐條標示符合／部分符合／不符合／無法判斷，附依據 |
| 風險考量 | 跳槽頻率、空窗、職級落差、薪資、地點等，附嚴重度與驗證方式 |
| 需要補充了解 | 打電話給人選時可以直接問的問題，以及為什麼要問 |
| 溝通切入點 | 向人選介紹職缺時最能打動他的角度 |

另外還會產出：職缺分析（必要／加分／排除條件、**建議先向客戶確認的事項**）、整體推薦總結（優先聯絡名單、人選比較、人才庫缺口與搜尋建議），並可匯出 Excel (CSV) 與 Markdown 報告。

### 資料來源

1. **電腦裡的資料夾**：PDF、Word（.docx / .doc）、PowerPoint（.pptx / .ppt）、txt。會包含子資料夾。
   - 掃描檔（圖片型 PDF）會直接把 PDF 交給 AI 閱讀。
   - 舊版 .doc / .ppt 需要安裝 [LibreOffice](https://www.libreoffice.org/)，或另存成新格式。
   - 內容完全相同的檔案（例如同一份履歷的 Word 和 PDF 版）只會算一次。
2. **Google Sheet**：第一列是欄位名稱，每一列是一位人選（欄位名稱含「姓名」或「Name」會自動當作人選姓名）。
   - 最簡單：Sheet 的共用設定改為「知道連結的任何人都能檢視」，把網址貼進設定即可。網址中的 `#gid=` 決定讀哪個分頁。
   - 不想公開：建立 Google Cloud 服務帳戶，把 Sheet 共用給服務帳戶的 email，在設定中填入金鑰檔路徑，並執行 `pip install gspread`。

### 運作方式

1. AI 分析 JD → 拆出必要條件、加分條件、評分維度與中英文搜尋關鍵字（含同義詞）
2. 用關鍵字在本機快速粗篩整個人才庫，取最相關的前 N 位（預設 20，可在設定調整）
3. AI 逐一深度評估這 N 位人選（可同時評估多位）
4. AI 綜合比較，產出推薦總結

履歷文字解析結果會快取在 `.cache/`，之後只會重新讀取新增或修改的檔案；每次篩選結果也會存在 `.cache/runs/`，可在「歷史紀錄」重新開啟。

### 安裝與啟動

需要 Python 3.10 以上，以及 Anthropic API 金鑰（到 https://console.anthropic.com 申請）。

**1. 設定 API 金鑰**

- Windows（命令提示字元，設定一次即可，設定後重開視窗）：
  ```
  setx ANTHROPIC_API_KEY "sk-ant-你的金鑰"
  ```
- macOS / Linux：在 `~/.zshrc` 或 `~/.bashrc` 加上
  ```
  export ANTHROPIC_API_KEY="sk-ant-你的金鑰"
  ```

**2. 啟動**

- Windows：雙擊 `start.bat`
- macOS / Linux：執行 `./start.sh`

第一次啟動會自動建立虛擬環境並安裝套件，接著瀏覽器會打開 http://127.0.0.1:5000 。

**3. 設定資料來源**

到「設定」頁面填入履歷資料夾路徑與 Google Sheet 網址並儲存（會寫入 `config.json`，範例見 `config.example.json`）。到「人才庫」按「重新掃描」確認讀到的人選與無法讀取的檔案。

**4. 開始使用**

在「新篩選」貼上 JD，補充資訊欄可以寫薪資範圍、地點、客戶偏好、排除條件等，按「開始推薦人選」。評估完成的人選會陸續出現，點擊卡片展開完整分析。

### 費用與速度

預設使用 Claude Opus 5.5、評估深度 `high`。每位人選評估約 30–90 秒（預設同時評估 4 位），20 位人選大約 5–10 分鐘。想要更快更省，可在設定把評估深度改為 `medium` 或降低評估人數上限。

### 隱私

- 網頁只在本機（127.0.0.1）開啟，其他電腦無法連線。
- 履歷內容會傳送到 Anthropic API 進行評估。透過 API 傳送的資料預設不會被用來訓練模型；請依你公司與人選同意的個資規範使用。
- `config.json`、`.cache/`（含履歷文字快取與評估結果）已列入 `.gitignore`，不會被上傳到 GitHub。

# 履歷篩選推薦工具

貼上職缺 JD，工具會從你電腦裡的履歷（PDF、Word、PPT）和 Google Sheet 人才庫中，找出最合適的人選。每位人選都會列出：

- **評分**（0–100）與**合適度**（強烈推薦／推薦／可考慮／不推薦）
- **推薦原因**（引用履歷內容）、**必要條件逐條檢核**、與職缺的**落差**
- **風險考量**（高／中／低，附驗證方式）
- **需要補充了解的資訊**（打電話時可以直接問的問題，以及為什麼要問）
- 向人選介紹職缺的**溝通切入點**

另外會產出職缺分析（含「建議先向客戶確認的事項」）、推薦總結、優先聯絡名單，並可匯出 Excel。

還有 **AI 助理聊天**：像跟真人同事對話一樣，請它在人才庫找人、比較人選、寫邀約訊息、規劃面試問題。

**完全免費**：AI 在你自己的電腦上執行（使用免費的 Ollama），不需要 API 金鑰，**履歷也不會傳到網路上**。

## 安裝步驟（只需要做一次，約 30 分鐘）

以下以 Windows 為例。Mac 的差異寫在最後面。

### 步驟 1：安裝 Python

1. 打開 https://www.python.org/downloads/ ，按黃色的「Download Python」按鈕。
2. 執行下載的安裝檔。**第一個畫面最下方務必勾選「Add python.exe to PATH」**，再按「Install Now」。
3. 出現「Setup was successful」就完成了。

### 步驟 2：安裝 Ollama（免費的本機 AI）

1. 打開 https://ollama.com/download ，下載 Windows 版並安裝。
2. 安裝完成後，Ollama 會在背景執行（螢幕右下角工作列會出現一隻羊駝圖示）。

### 步驟 3：下載 AI 模型

1. 按鍵盤 `Windows 鍵 + R`，輸入 `cmd`，按 Enter，會跳出黑色視窗。
2. 依你電腦的記憶體選一個評估模型，輸入指令後按 Enter（記憶體大小可在「設定 → 系統 → 關於」查看）：

   | 電腦記憶體 | 輸入的指令 | 下載大小 |
   |---|---|---|
   | 8GB | `ollama pull qwen3:4b` | 約 2.5GB |
   | **16GB（多數電腦）** | **`ollama pull qwen3:8b`** | 約 5GB |
   | 32GB 以上或有獨立顯卡 | `ollama pull qwen3:14b` | 約 9GB |

3. 再輸入下面這行，下載「語意比對」模型（用來在幾千份履歷中找出意思相近的人，不只比對關鍵字）：
   ```
   ollama pull bge-m3
   ```
4. 兩個都出現 `success` 就完成了，可以關掉黑色視窗。

### 步驟 4：下載這個工具

1. 打開 https://github.com/eddyrockyou/headhunter-tool/tree/claude/compassionate-newton-wfsd64
2. 按綠色的「Code」按鈕 →「Download ZIP」。
3. 對下載的 ZIP 按右鍵 →「解壓縮全部」，放到你好找的地方，例如「文件」資料夾。

### 步驟 5：啟動

1. 進入解壓縮後的資料夾，**雙擊 `start.bat`**。
2. 第一次會自動安裝需要的套件（約 1–3 分鐘），之後瀏覽器會自動打開工具頁面。
3. **使用期間不要關掉黑色視窗**；關掉它，工具就會停止。

> 如果 Windows 跳出「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

### 步驟 6：設定資料來源

1. 在工具頁面點上方的「**設定**」。
2. **履歷資料夾**：一行填一個資料夾路徑，子資料夾也會一起讀。
   - 取得路徑的方法：在檔案總管打開那個資料夾，點上方的網址列，複製裡面的文字（例如 `C:\Users\Eddy\Documents\履歷`）。
3. **Google Sheet**：一行填一個，格式是 `名稱 | 網址`。
   - Sheet 要先開放讀取：在 Google Sheet 按右上角「共用」→ 一般存取權改成「**知道連結的任何人**」（檢視者）。
   - Sheet 的第一列要是欄位名稱（例如：姓名、現職、年資、技能…），每一列是一位人選。
4. **AI 引擎**維持「本機免費 AI」。**本機評估模型**填你在步驟 3 下載的模型（例如 `qwen3:8b`）。
5. 按「**儲存設定**」。
6. 點上方的「**人才庫**」→「**重新掃描**」，確認人選數量正確，並查看哪些檔案讀不到。

## 每次使用

1. 雙擊 `start.bat`。如果 Ollama 沒有在執行，先從開始選單打開 Ollama。
2. 在「**新篩選**」貼上 JD；補充資訊欄可寫薪資範圍、地點、客戶偏好、排除條件等。
3. 按「**開始推薦人選**」。評估完成的人選會陸續出現，點卡片可以展開完整分析。
4. 結果會自動保存，之後可在「**歷史紀錄**」重新打開，也可以匯出 Excel 或報告。

## AI 助理（聊天）

點上方第一個分頁「**AI 助理**」，直接輸入問題，按 Enter 送出（Shift+Enter 換行）。回答會一個字一個字出現，回答途中可以按「停止」。

**兩種用法：**

1. **直接問人才庫**（「對話依據」選「不指定篩選結果」）
   - 「人才庫裡有誰做過半導體製程、英文好？」
   - 「找 5 年以上經驗的後端工程師，列出姓名和現職」
2. **針對某次篩選結果討論**（「對話依據」選那次篩選，或在結果頁按「用 AI 助理討論」）
   - 「比較前三名的優缺點，我該先聯絡誰？」
   - 「幫我寫一則給第一名的 LinkedIn 邀約訊息」
   - 「第二名的跳槽風險要怎麼在電話中確認？」

也可以問跟人選無關的事，例如「幫我把這段 JD 改寫得更吸引人」或「面試資深業務經理要問哪些問題？」。

**使用小提醒：**
- 勾選「每次提問時搜尋整個人才庫」時，每次提問都會先找出最相關的 5 位人選給 AI 參考。回答下方的「參考了人才庫中 N 位人選」可以點開，看是哪幾份履歷。
- AI 只會根據找到的履歷回答，找不到的人它會說沒有，不會編造。想找特定的人，問題寫得越具體越好（技能、年資、產業、地點）。
- 對話紀錄存在你自己的瀏覽器裡；按「清除對話」可以重新開始。

### 需要多久？

以下是粗估時間，實際依電腦速度而定：

| 項目 | 第一次 | 之後 |
|---|---|---|
| 讀取幾千份履歷 | 數分鐘 | 幾秒（只讀新增或修改的檔案） |
| 語意比對整個人才庫 | 可能要半小時到一小時以上 | 幾秒（結果會記住） |
| 深度評估 20 位人選 | 有獨立顯卡：數分鐘；一般筆電：約 20–60 分鐘 | 同左 |
| AI 助理回答一個問題 | 有獨立顯卡：數秒；一般筆電：約 30 秒到數分鐘 | 同左 |

想要更快，可以在「設定」把「每次深度評估人數上限」調低（例如 10），或改用較小的模型。

## 工具怎麼從幾千筆裡挑人

1. **AI 分析 JD**：拆出必要條件、加分條件、評分維度，以及中英文搜尋關鍵字（含同義詞，例如 BD ＝ 業務開發）。
2. **全庫粗篩（免費、快速）**：用「關鍵字＋語意比對」把幾千位人選全部排一次序，取前 20 位。
3. **AI 深度評估**：逐一仔細評估這 20 位，產出評分、原因、風險和要補問的問題。
4. **AI 推薦總結**：比較這幾位人選，排出優先聯絡順序。

## 想要更準的第二意見（選用，免費）

本機 AI 的判斷已經夠用來排序和初步篩選，但細膩程度不如 Claude。需要時可以這樣做：

1. 在結果頁按「**匯出給 Claude 精評**」，會下載一個檔案，內含 JD 和前 10 名的履歷。
2. 打開 https://claude.ai （免費帳號即可），把檔案拖進對話框送出。

注意：這一步會把這 10 份履歷上傳到 claude.ai，請依你們的個資規範決定是否使用。

## 常見問題

- **網頁上方出現紅色提示「Ollama 沒有在執行」**：從開始選單打開 Ollama，再重新整理網頁。
- **提示「還缺模型」**：照提示在黑色視窗（cmd）執行 `ollama pull 模型名稱`。
- **有些 PDF 被略過**：掃描檔（圖片型 PDF）沒有文字，本機 AI 讀不到。可以用 Adobe 或 Google 雲端硬碟的 OCR 功能轉成文字型 PDF。
- **舊版 .doc / .ppt 讀不到**：安裝免費的 [LibreOffice](https://www.libreoffice.org/)，或用 Word / PowerPoint 另存成 .docx / .pptx。
- **很長的履歷**：本機 AI 只讀前 2 萬字，結果卡片上會註明。
- **私人 Google Sheet（不想開放連結）**：需要建立 Google Cloud 服務帳戶，把 Sheet 共用給服務帳戶的 email，在設定中填入金鑰檔路徑，並在工具資料夾執行 `.venv\Scripts\pip install gspread`。

## Mac 的差異

- 步驟 1：Mac 通常已內建 Python 3；沒有的話從 python.org 安裝。
- 步驟 2：下載 Mac 版 Ollama，拖進「應用程式」後打開。
- 步驟 3：用「終端機」（應用程式 → 工具程式 → 終端機）輸入同樣的 `ollama pull` 指令。
- 步驟 5：在終端機輸入 `cd ` 加一個空格，把工具資料夾拖進終端機視窗，按 Enter，再輸入 `./start.sh` 按 Enter。

## 隱私

- 使用本機 AI 時，履歷只在你的電腦上處理，不會上傳。
- 工具網頁只能從你自己的電腦開啟（127.0.0.1），同網路的其他電腦連不進來。
- 設定檔 `config.json` 和快取資料夾 `.cache/`（含履歷文字與評估結果）不會被上傳到 GitHub。
